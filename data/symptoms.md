## fix 스킬의 기본 동작

```
기본 경로(권장) : 검사 15개 전부 실행 → 실패한 것부터 보여줌 → 조치 안내
보조 경로       : 그래도 원인을 못 찾으면 → 위 사전으로 물어봄(🔴부터)
```

검사 15개를 전부 돌려도 몇 초면 끝난다. 묻지 않고 먼저 찾아주는 편이 낫고, 이미 만든 CHECK 판정을 최대로 활용한다. 증상 사전은 **검사로 안 잡히는 경우**(사양·오해·타이밍)를 위한 보조 수단이다.
