SoDam-CCC — 텔레그램으로 내 컴퓨터에 말 걸기

🇰🇷 한국어 기본 문서입니다. English version: README.en.md 이 문서는 개발을 한 번도 안 해본 사람, AI·메신저·컴퓨터·모바일 기기를 처음 다루는 사람을 기준으로 씁니다. “터미널이 뭔지”, “경로가 뭔지” 같은 것도 처음 나올 때 한 줄로 풀어 설명합니다.

✅ 지금 이 문서가 서 있는 위치를 정직하게 밝힙니다 (2026-09-01 기준): - 실제로 이 PC에서 라이브로 확인된 것: 설치 12단계 전체 흐름(마켓플레이스 등록 → 플러그인 설치 → 토큰 등록 → 페어링 → 안전 잠금), /sodam-ccc:status·/sodam-ccc:fix 정상 동작, 그리고 폰에서 보낸 메시지가 실제로 PC를 거쳐 답장으로 돌아오는 것(왕복 성공)까지 전부 실제 화면으로 직접 확인했습니다. (“안녕” → “안녕하세요! 연결됐어요. 무엇을 도와드릴까요?”) - 이 확인 과정에서 실제로 두 번 막혔던 흔한 함정(① 설정 폴더 위치 불일치 ② 폴더 신뢰 확인 화면에서 멈춤)이 있었습니다. 원인과 해결법을 감추지 않고 16. 문제·오류 대처 방법에 그대로 남겨뒀습니다 — 같은 상황을 겪어도 당황하지 않도록 하기 위해서입니다. - 이 문서의 “이렇게 나오면 정상입니다” 문구는 더 이상 예상이 아니라, 실제로 확인된 동작을 기준으로 씁니다. 다만 텔레그램 채널 기능 자체가 아직 “research preview”(정식 출시 전 시험판)라 앞으로 바뀔 수 있다는 점은 여전합니다.

1. 이게 뭔가요?

한 문장 요약: 폰(텔레그램 앱)으로 문자를 보내면, 내 컴퓨터에 있는 Claude Code(AI 코딩 도우미)가 그 문자를 읽고 일을 해준 뒤, 다시 폰으로 답장을 보내주는 기능(공식 이름: Claude Code Channels)을 — 처음 설치할 때, 다시 설치할 때, 고장났을 때 헤매지 않도록 도와주는 도구입니다.

[폰에서 "회의록 정리해줘" 라고 보냄]
              │
              ▼
   ( SoDam-CCC 가 설치를 도와준 그 통로를 타고 )
              │
              ▼
[내 컴퓨터의 Claude Code 가 일을 함]
              │
              ▼
   [폰으로 결과 답장이 옴]

SoDam-CCC 자신은 문자를 보내거나 받는 기능이 아닙니다. 문자를 주고받는 기능(Claude Code Channels)은 Anthropic(Claude Code를 만든 회사)의 공식 기능입니다. SoDam-CCC는 그 공식 기능을 설치·점검·수리해 주는 조수입니다.

할 수 있는 것

  • 지금 설치가 12단계 중 몇 단계까지 됐는지 검사해서 알려줍니다.
  • 아직 안 된 단계만 골라서 순서대로 안내합니다(이미 된 건 다시 안 시킵니다).
  • 폰이 갑자기 먹통일 때 원인 후보를 검사해서 어디가 문제인지 짚어줍니다.
  • “허용된 사람만 명령을 보낼 수 있게” 잠그는 안전 설정을 빠뜨리지 않게 강제합니다.
  • 채널을 켜는 프로세스(뒤에서 설명)를 사용자 동의를 받은 뒤 대신 띄우고, 대신 꺼줄 수 있습니다.

할 수 없는 것

  • Claude Code 자체를 설치해주지 않습니다(Claude Code가 이미 깔려 있고 로그인돼 있다고 전제합니다).
  • 텔레그램 봇을 대신 만들어주지 않습니다(봇을 만드는 건 폰에서 사람이 직접 하는 절차입니다).
  • 봇 토큰(비밀번호 같은 값)을 대신 입력해주지 않습니다 — SoDam-CCC는 이 값을 아예 보지도, 묻지도, 저장하지도 않습니다.

5. 다운로드 / 설치 방법

  1. Claude Code 안에서 아래를 입력합니다:

    /sodam-ccc:install

  2. 지금 12단계 중 몇 단계까지 준비됐는지 검사한 뒤, 아직 안 된 것만 순서대로 안내합니다.

  3. 안내 중 일부는 폰에서 직접 해야 합니다(봇 만들기·토큰 확인·페어링(폰과 봇을 연결하는 절차)). 그때마다 “폰에서” 또는 “Claude Code 안에서”인지 정확히 알려줍니다.

  4. 안전 잠금(허용된 사람만 명령을 보낼 수 있게 막는 설정)까지 끝나야 설치가 “완료”로 표시됩니다. 이 단계는 절대 생략되지 않습니다 — 안전 잠금이 안 됐는데 SoDam-CCC가 “완료됐습니다”라고 말하는 일은 설계상 없습니다.

✅ 이렇게 나오면 정상입니다(설계 기준): 매 단계마다 지금 몇 단계인지(예: “7/12단계”)와 다음에 뭘 하면 되는지 한 가지가 화면에 나옵니다. 이미 끝난 단계는 “이미 되어 있습니다”로 짧게만 표시되고 건너뜁니다.

💡 설치 도중 플러그인 범위(스코프)를 고르라는 화면이 뜨면 반드시 user를 선택하세요. 다른 걸 고르면 나중에 “다른 폴더에서 하니까 안 돼요”(16번 SYM-05) 문제가 생깁니다.

💡 플러그인을 못 찾는다고 나오면 — 자동 업데이트가 꺼진 PC일 수 있습니다. 이럴 땐 Claude Code 안에서 /plugin marketplace update claude-plugins-official을 한 번 입력한 뒤 다시 시도하면 됩니다. /sodam-ccc:install이 이 상황도 검사해서 알려줍니다.

⚠️ 재설치라면(기존 봇이 있다면): SoDam-CCC는 아무 기록도 남기지 않으므로, 지금 이 순간의 검사 결과 하나만으로 판단합니다. 이미 토큰이 등록돼 있으면 “새 봇을 만드세요”라고 시키지 않고 기존 봇을 그대로 씁니다 — 사람 손이 가는 단계가 3개 이하(토큰 복사·페어링 코드 확인·페어링 승인)로 줄어듭니다. 신규 설치는 여기에 “봇 만들기”가 하나 더 붙어 4개 이하입니다.

⚠️ 안 되면 → 17. FAQ #2(봇이 답을 안 함) 또는 Claude Code 안에서 /sodam-ccc:fix를 입력해 보세요.

6. 빠른 시작 (3분 안에 확인)

지금 상태를 가장 빨리 파악하는 순서입니다.

  1. Claude Code 안에서 /sodam-ccc:status 입력 → 지금 몇 단계인지, 뭐가 남았는지 바로 보여줍니다.
  2. 부족한 게 있으면 Claude Code 안에서 /sodam-ccc:install 입력 → 남은 것만 순서대로 안내받습니다.
  3. “N/12단계”가 전부 채워지고 안전 잠금까지 끝나면, 폰 텔레그램에서 내 봇에게 “안녕”이라고 보내봅니다.
  4. 답장이 오면 성공입니다. 조용하면 → 17. FAQ #3 또는 /sodam-ccc:fix.

✅ 위 1~4번(상태 점검·설치 마법사·폰 왕복) 전부 이 PC에서 실제로 여러 차례 실행해 정상 동작을 확인했습니다.

7. 실행 방법

텔레그램으로 명령을 받으려면 Claude Code를 평소와 다른 특별한 방식으로 켜야 합니다. 일반 claude 명령으로 켠 세션은 폰 메시지를 받지 못합니다.

  • PowerShell(윈도우 검색창에 “PowerShell”을 입력하면 나오는 프로그램)에서 입력:

    claude --channels plugin:telegram@claude-plugins-official

  • 이렇게 켠 세션이 떠 있는 동안에만 폰 메시지를 받을 수 있습니다. 창을 닫으면 그 순간부터 못 받습니다.

  • /sodam-ccc:install이 이 단계가 필요할 때 정확한 명령을 다시 보여줍니다.

🤖 SoDam-CCC가 대신 켜줄 수도 있습니다

위 명령을 사람이 PowerShell을 직접 열어 입력하는 대신, Claude Code 안에서 /sodam-ccc:install(또는 /sodam-ccc:fix)에게 “채널을 켜줘”라고 하면, SoDam-CCC가: 1. 먼저 이미 켜져 있는지부터 확인합니다(중복으로 두 개를 띄우면 서로 충돌할 수 있어 절대 두 번 안 띄웁니다). 2. 안 켜져 있으면, 실행할 명령을 화면에 그대로 보여주고 동의를 구한 뒤에만 새 PowerShell 창을 대신 띄웁니다. 3. 그 창은 숨기지 않고 눈에 보이게 띄웁니다 — 몰래 백그라운드로 실행하지 않습니다. 4. 만약 이 PC의 다른 보호장치가 자동 실행 자체를 막으면(정상적인 이중 안전장치입니다), “PowerShell을 열고 이 명령을 직접 입력해주세요”로 자동 전환해 안내합니다.

채널을 끄고 싶을 때도 마찬가지로, SoDam-CCC가 띄운 그 창을 “꺼줘”라고 요청하면 동의를 받은 뒤 대신 종료해줍니다.

✅ 이렇게 나오면 정상입니다(설계 기준): 평소 Claude Code를 켤 때와 같은 화면이 뜨고, 특별한 오류 문구가 없으면 정상입니다.

⚠️ 이 폴더에서 처음 실행하는 경우(신뢰 확인 화면): “Is this a project you created or one you trust? ❯ No, exit / Yes, I trust this folder”처럼 이 폴더를 신뢰하는지 묻는 화면이 뜨고 응답할 때까지 완전히 멈춰있을 수 있습니다. 이건 고장이 아니라 Claude Code 자체의 정상 보호 기능이며 SoDam-CCC와 무관합니다. ↓(아래 방향키)로 “Yes, I trust this folder”로 옮긴 뒤 Enter를 누르면 계속 진행됩니다. 기본 선택은 “No, exit”(종료)이므로, 방향키 없이 그냥 Enter만 누르면 꺼져버립니다 — 반드시 방향키로 옮긴 뒤 누르세요.

⚠️ PC를 끄거나 이 창을 닫으면 폰 메시지가 사라집니다(17. FAQ #1). 보냈는데 답이 없으면 → 17. FAQ #2·#3 또는 /sodam-ccc:fix를 확인하세요.

8. 사용 방법 (폰에서 뭐라고 보내면 되나)

설치가 끝나고 채널이 켜져 있으면, 폰 텔레그램에서 내 봇 채팅방에 그냥 평소 Claude Code에게 말하듯 자연어(보통 글)로 보내면 됩니다.

예시:
"오늘 날씨 어때?"                (봇이 아니라 PC의 Claude Code가 실제로 작업 수행)
"방금 만든 파일 목록 보여줘"
"이 폴더에서 제일 큰 파일 찾아줘"

안 되는 것 (설계상 원래 이런 것 — 고장 아님)

  • 슬래시 명령은 안 됩니다. /clear·/compact 같은 명령은 터미널 화면 전용이라 채널로는 실행되지 않습니다(공식 기능요청 이슈로 개선 요청 중).
  • “어제 그거”처럼 지난 대화를 되짚는 건 못 알아듣습니다. 텔레그램 봇은 과거 메시지를 다시 찾아볼 수 없고, 세션이 바뀌면 맥락도 이어지지 않습니다. “그 파일 이름이 뭐였는지 다시 알려줘”처럼 필요한 내용을 다시 말해주면 됩니다.
  • 답변이 이상하게 잘려 보일 때가 있습니다. 텔레그램 메시지 길이 제한 때문이며, 설정을 조정할 수 있습니다(16번 SYM-06).

위험한 작업을 시켰을 때

Claude Code가 Bash(명령 실행)·Write(파일 쓰기) 같은 위험도 높은 작업을 하려면, PC 터미널 화면에 승인 요청이 뜨고 그 순간 세션이 멈춰서 기다립니다. 폰에서 이 요청을 승인할 수 있습니다: - 텔레그램 메시지에 뜨는 버튼을 누르거나 - yes <5글자코드> 형식의 텍스트를 직접 입력

승인하기 전까지는 그 작업이 진행되지 않습니다. 자세한 원리는 15. 보안·데이터 흐름에서 다룹니다.

SoDam-CCC 자신은 이 그림 어디에도 없습니다 — SoDam-CCC는 이 흐름이 살아있을 수 있게 설정을 검사하고 도와주는 조수일 뿐, 메시지가 지나가는 통로 자체가 아닙니다.

신뢰 경계 — SoDam-CCC가 지키는 안전선

일반적인 웹앱과 이 도구는 성격이 다릅니다. 서버·로그인·회원가입이 없는 로컬(내 PC) 전용 도구입니다.

개념 SoDam-CCC에서는
서버·데이터베이스·웹페이지 없음 — 전부 내 PC 안에서만 동작
로그인·회원·결제 없음 — 나 혼자 쓰는 개인용
누가 내 PC에 명령을 내릴 수 있는가(인가 경계) 텔레그램 허용목록 — 여기 등록된 사람만
가장 중요한 비밀 봇 토큰(텔레그램이 발급하는 값)
가장 위험한 권한 작업 승인권 — 승인하면 실제로 파일 쓰기·명령 실행이 일어남

설계 원칙 3가지 (자세한 내용은 15번에서)

  1. 안 읽으면 샐 수 없다 — 토큰 파일은 존재 여부만 확인하고 내용은 절대 안 엶
  2. 직접 안 고치면 망가뜨릴 수 없다 — 설정 변경은 전부 Claude Code의 공식 명령을 통해서만
  3. 고정 문자열만 실행한다 — 검사·진단 명령에 외부에서 읽은 값을 끼워 넣지 않음(명령어 주입 방지)

15. 보안 · 데이터 흐름

내 정보는 어디에 저장되나

봇 토큰(가장 민감한 값)은 내 컴퓨터 안에만 저장됩니다(정확한 위치는 PC마다 다를 수 있습니다 — 12번 참고). 외부 서버로 전송되거나 SoDam-CCC가 어딘가로 복사하는 일은 없습니다.

SoDam-CCC는 이 파일의 내용을 절대 열어보지 않습니다. 파일이 “있는지 없는지”만 확인합니다 — 마치 봉투를 뜯지 않고 “봉투가 있는지”만 확인하는 것과 같습니다. 그래서 SoDam-CCC 자체가 토큰을 유출할 방법이 구조적으로 없습니다.

허용목록 = 승인 권한

텔레그램 허용목록에 등록된 사람은 단순히 “메시지를 보낼 수 있는 사람”이 아니라, 내 PC에서 파일 쓰기·명령 실행 같은 위험한 작업을 승인할 수 있는 사람입니다. 승인 요청은 허용목록에 있는 전원에게 보내집니다. 그래서: - SoDam-CCC는 허용목록에 본인 외 다른 사람을 절대 자동으로 추가하지 않습니다. - 설치가 끝나는 순간, 이 권한이 얼마나 강력한지 반드시 화면에 고지합니다. - 허용목록에 2명 이상이 있으면 /sodam-ccc:status가 경고로 알려줍니다.

3중 방어 (출력 규칙)

SoDam-CCC가 화면에 뭔가 보여줄 때 지키는 3단계 방어선입니다.

1층  안 읽는다      → 토큰 파일 내용에 애초에 접근하지 않음
2층  판정값만 쓴다   → "있음/없음/통과/실패"만 화면에 표시(원문 그대로 보여주지 않음)
3층  마스킹한다      → 혹시라도 토큰 형식 문자열이 화면에 나가려 하면 그 직전에 가림

위험한 작업 승인 흐름 (앞서 8번에서 다룬 것의 보안적 의미)

Claude Code가 파일을 쓰거나 명령을 실행하려면 승인이 필요합니다. 채널 모드에서는 이 승인 요청이 폰으로도 옵니다 — 이게 편리하지만 동시에 가장 강력한 권한이므로, 허용목록 관리가 이 도구에서 가장 중요하게 다뤄지는 이유입니다.

스크린샷·화면 공유 시 주의

이 도구의 실행 화면을 캡처해서 남에게 보여주거나 인터넷에 올릴 계획이 있다면, 내 계정 폴더 경로·사용자 아이디·토큰 형태의 문자열이 찍히지 않았는지 반드시 확인하세요. SoDam-CCC 자체 출력은 이런 값을 안 보여주도록 설계돼 있지만, PowerShell 창이나 다른 화면까지 SoDam-CCC가 대신 가려주지는 못합니다.

위험 설정 자가 점검

/sodam-ccc:status·/sodam-ccc:fix는 매번 아래를 자동으로 함께 점검합니다. - 허용목록 인원이 2명 이상인가 (경고) - 단체방(그룹) 허용이 켜져 있는가 (경고) - --dangerously-로 시작하는 위험한 실행 옵션을 쓴 흔적이 있는가 (경고)

SoDam-CCC는 위험한 실행 옵션(예: 권한 확인을 건너뛰는 옵션)을 절대 권하거나 실행하지 않습니다.

✅ 2026-09-01 재점검: 위 세 가지 자가 점검 항목을 이 PC에서 직접 다시 실행해 전부 안전한 상태(허용목록 1명, 단체방 허용 0개, 위험 옵션 사용 흔적 없음)임을 확인했습니다. 이 과정에서 “단체방 허용 개수”를 세는 검사 방식 자체에 있던 작은 함정(0개인 정상 상태를 빈 값으로 잘못 표시할 수 있던 문제)을 찾아 고쳤습니다.

16. 문제 · 오류 대처 방법

/sodam-ccc:fix가 자동으로 검사·안내해주지만, 아래는 자주 겪는 증상을 미리 알아두고 싶을 때 참고하는 표입니다. 빈도: 🔴 매우 흔함 · 🟡 가끔 · 🟢 드묾 · ⚪ 사양(고장 아님).

🔴 봇이 아무 반응이 없어요

가장 흔한 원인 순서대로: ① --channels 없이 그냥 claude로 실행함 → 종료 후 7번의 명령으로 다시 실행. ② Claude Code 세션 자체가 꺼져 있음 → 세션을 켠다(PC와 세션 둘 다 켜져 있어야 함). ③ 플러그인이 아직 설치가 안 됨. ④ 토큰이 아직 등록 안 됨.

⑤ 채널 창은 떠 있는데 계속 안 되는 경우 — 봇 토큰이 무효화됐을 가능성: BotFather에서 그 봇을 삭제했거나 다시 발급받았을 때 생깁니다. 텔레그램 앱에서 BotFather와의 대화를 열어 그 봇이 아직 있는지 먼저 확인하세요. 없거나 안 맞으면 10번의 토큰 등록 명령으로 새 토큰을 다시 등록하면 됩니다.

⑥ 서버가 켜지자마자 곧바로 꺼지는 경우 — 설정 폴더 위치 불일치(2026-09-01 실제로 겪은 사례): 토큰은 분명 등록했는데, 이 PC의 Claude Code 설정 폴더 위치가 예전에 바뀐 적이 있다면 토큰이 엉뚱한(예전) 위치에만 저장돼 있을 수 있습니다. 이때는 10번의 토큰 등록 명령을 다시 한번 실행하면 지금 기준으로 올바른 위치에 새로 저장됩니다. 그래도 안 되면 /sodam-ccc:fix에게 알려주세요 — 두 위치를 직접 비교해 옛 파일을 옮겨주는 대처법을 안내합니다.

⑦ 채널을 켠 창이 뭔가에 멈춰 있는 경우 — “이 폴더를 신뢰합니까?” 확인 화면(2026-09-01 실제로 겪은 사례): 그 폴더에서 Claude Code를 처음 실행하면 신뢰 여부를 묻는 화면이 뜨고, 대답할 때까지 그 창 전체가 멈춥니다(고장 아님, Claude Code 자체의 정상 보호 기능). 그 창을 직접 열어 화면에 “Is this a project you created or one you trust?” 같은 질문이 있는지 확인하세요. 있으면 7번에 적은 대로 ↓(아래 방향키)로 “Yes, I trust this folder”를 고른 뒤 Enter를 누르면 이어서 진행됩니다.

🔴 메시지는 간 것 같은데 답이 없어요

가장 흔한 이유는 PC 터미널 화면에 승인 요청이 떠서 대기 중인 것입니다(고장 아님). 폰에서 버튼을 누르거나 yes <5글자코드>를 보내 승인하세요. 작업 자체가 오래 걸리는 중일 수도 있습니다 — ackReaction(받음 표시)을 켜두면 최소한 “전달은 됐다”는 걸 바로 알 수 있습니다.

🔴 /plugin install이 실패해요

마켓플레이스가 아직 등록 안 됐거나(/plugin marketplace add anthropics/claude-plugins-official), 카탈로그가 낡았을 수 있습니다(자동 갱신이 꺼진 PC라면 /plugin marketplace update claude-plugins-official 후 재시도).

🟡 페어링 코드가 안 와요

이미 안전 잠금(allowlist)이 걸려 있는데 내 계정이 아직 허용목록에 없는 상태일 수 있습니다. 이때는 정책을 잠시 pairing으로 되돌려 페어링한 뒤, 반드시 다시 allowlist로 잠가야 합니다(안 잠그면 설치가 “완료”로 인정되지 않습니다). 봇 토큰 자체가 틀렸을 가능성도 확인하세요.

🟡 다른 폴더에서 하니까 안 돼요

설치할 때 스코프를 project로 골랐을 가능성이 큽니다. user 스코프로 다시 설치하세요(5번 참고).

🟡 어제까지 잘 되던 게 갑자기 먹통이에요

Claude Code를 업데이트한 직후라면, 업데이트로 인한 일시적 회귀(공식 기능의 시험판 특성)일 수 있습니다. 버전이 바뀌었는지 확인하고, 공개된 이슈를 확인해 보세요. MCP(외부 도구 연결) 재연결 실패일 수도 있으니 세션을 재시작해보는 것도 방법입니다.

🟢 답변이 이상하게 잘려서 와요

텔레그램 메시지 길이 제한 때문입니다. 답변을 나누는 방식(청크) 설정을 조정할 수 있습니다.

🟢 설치했는데 채널이 등록이 안 됐대요

조직(회사) 계정 정책이 꺼져 있을 수 있습니다(단, 개인 Pro/Max 계정은 해당하지 않습니다). 또는 --channels 뒤에 봇 이름을 정확히 안 적었을 수 있습니다.

⚪ “어제 그거”라고 했는데 못 알아들어요 — 고장 아님

텔레그램 봇은 과거 대화 내용을 다시 찾아볼 수 없습니다. 필요한 내용을 다시 말해주세요.

슬래시 명령은 터미널 화면 전용이라 채널로는 실행되지 않는 것이 현재 사양입니다.
