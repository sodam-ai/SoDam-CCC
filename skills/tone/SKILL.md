# 말투 규칙 (SoDam-Loop의 tone 패턴 재사용)

이 문서는 SoDam-CCC의 모든 출력(스킬 결과)에 적용되는 공통 규칙이다. `install`·`status`·`fix` 스킬은 사용자에게 무언가를 보여주기 직전에 이 규칙을 따른다. 대상 독자는 "개발을 한 번도 안 해본 사람 · 6개월 뒤의 나"다.

## 반드시 지킬 것

1. **전문용어는 처음 나올 때 한 줄로 풀어 쓴다.** (예: "페어링(폰과 봇을 연결하는 절차)")
2. **다음에 뭘 할지 한 가지만 제시한다.** 여러 선택지를 한꺼번에 던지지 않는다.
3. **판정 근거를 함께 보여준다.** "무엇을 보고 그렇게 판단했는지"를 짧게 남긴다.
4. **진도는 숫자로.** "7/12단계"처럼 어디까지 왔는지 항상 보여준다.
5. **탓하는 톤 금지.** "잘못하셨습니다" ❌ → "이럴 때가 있습니다. 이렇게 하면 됩니다" ✅
6. **막혔을 때 갈 곳을 알려준다.** (다음 조치 또는 `fix` 실행 안내)
7. **"반드시 됩니다" 같은 보장을 쓰지 않는다.** 확인된 것과 미확인을 구분한다.
8. **명령을 보여줄 땐 어디에 입력하는지 항상 밝힌다.** (PowerShell / Claude Code 안 / 폰 텔레그램)

## 출력 직전 마스킹 (최종 방어선 — C-6)

> 1층(안 읽는다)·2층(판정값만 쓴다)이 이미 대부분을 막지만, 혹시 모를 실수에 대비한 **최종 방어선**이다. 모든 스킬은 사용자에게 무언가를 보여주기 **직전에** 아래 패턴을 검사하고, 걸리면 그 부분을 가린다.

- **대상 패턴**: 텔레그램 봇 토큰 형식 — 숫자 하나 이상 + 콜론(`:`) + 영문자·숫자·`-`·`_` 35자 (예 형태: `123456789:ABCdefGHIjklMNOpqrSTUvwxYZ1234567`). 공식 Telegram Bot API가 공개한 형식이라, 실제 비밀값을 보지 않고도 형태만으로 식별할 수 있다.
- **동작**: 이 형식과 일치하는 문자열이 화면에 나가기 직전 보이면, 전체를 `(가려짐)`으로 바꿔서 표시한다. 무엇을 가렸는지는 말하되 원문은 어디에도 남기지 않는다.
- 정상적인 흐름에서는 이 규칙이 **발동할 일이 없어야 한다** — 1층·2층이 제대로 지켜지면 토큰 형식 문자열 자체가 출력 근처에 갈 일이 없다. 발동했다면 그 자체가 1층·2층 어딘가에 문제가 있다는 신호로 받아들인다.

## 예시

❌ "CHK-08 실패. dmPolicy가 pairing입니다."

✅ "🚫 지금 이 상태로는 완료로 볼 수 없어요 — 잠금 설정(정책)이 아직 '누구나 요청 가능(pairing)'으로 열려 있습니다.
　　→ **Claude Code 안에서** 아래를 입력하면 잠깁니다:
　　`/telegram:access policy allowlist`"
