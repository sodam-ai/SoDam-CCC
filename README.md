## 3. 사전 준비물 (있어야 하는 것)

- **스마트폰** (텔레그램 앱을 설치할 수 있는 것)
- **텔레그램(Telegram) 앱** — 메신저 앱 중 하나입니다. 폰 앱스토어에서 "Telegram"으로 검색해 설치하세요.
- **인터넷 연결** (폰·PC 둘 다)
- **켜져 있는 PC** — ⚠️ **PC가 꺼져 있으면 폰에서 보낸 메시지는 그냥 사라집니다.** (자세한 이유는 15번 "보안·데이터 흐름"에서 다룰 예정입니다)
- **Claude 유료 계정** (Pro 또는 Max)

## 4. 필요한 프로그램 (설치해야 하는 것)

| 프로그램 | 왜 필요한가 |
|---|---|
| **Claude Code** | 이 모든 기능이 그 위에서 동작합니다. **이미 설치·로그인돼 있다고 전제**합니다 — 이 프로젝트(SoDam-CCC)는 Claude Code 자체의 설치는 도와주지 않습니다. |
| **Bun** | 텔레그램 채널 기능이 내부적으로 이 프로그램으로 동작합니다. 없으면 `/sodam-ccc:install`이 알려줍니다. |
| **텔레그램 봇 플러그인** | 공식 Claude Code 마켓플레이스가 제공하는 부품입니다. `/sodam-ccc:install`이 설치를 안내합니다. |

> 정확한 설치 명령·버전은 상황마다 다를 수 있어 이 문서에 고정해두지 않습니다. `/sodam-ccc:install`을 실행하면 지금 무엇이 빠졌는지 검사해서 알려줍니다.

## 5. 다운로드 / 설치 방법

1. **Claude Code 안에서** 아래를 입력합니다:
   ```
   /sodam-ccc:install
   ```
2. 지금 몇 단계까지 준비됐는지 검사한 뒤, **아직 안 된 것만** 순서대로 안내합니다.
3. 안내 중 일부는 **폰에서** 직접 해야 합니다(봇 만들기·토큰 확인·페어링(폰과 봇을 연결하는 절차)). 그때마다 "폰에서" 또는 "Claude Code 안에서"인지 정확히 알려줍니다.
4. 안전 잠금(허용된 사람만 명령을 보낼 수 있게 막는 설정)까지 끝나야 설치가 "완료"로 표시됩니다. 이 단계는 절대 생략되지 않습니다.

> ✅ **이렇게 나오면 정상입니다**: 매 단계마다 지금 몇 단계인지(예: "7/12단계")와 다음에 뭘 하면 되는지 한 가지가 화면에 나옵니다. 이미 끝난 단계는 "이미 되어 있습니다"로 짧게만 표시되고 건너뜁니다.
> (실제 화면 문구는 실행해봐야 정확히 확인됩니다 — 여기 적은 건 설계상 이렇게 나오도록 만들어진 형태입니다.)

> 💡 **설치 도중 플러그인 범위(스코프)를 고르라는 화면이 뜨면 반드시 `user`를 선택하세요.** 다른 걸 고르면 나중에 "다른 폴더에서 하니까 안 돼요" 문제가 생깁니다.

> 💡 **플러그인을 못 찾는다고 나오면** — 자동 업데이트가 꺼진 PC일 수 있습니다. 이럴 땐 **Claude Code 안에서** `/plugin marketplace update claude-plugins-official`을 한 번 입력한 뒤 다시 시도하면 됩니다. `/sodam-ccc:install`이 이 상황도 검사해서 알려줍니다.

> ⚠️ **안 되면** → FAQ #2(봇이 답을 안 함) 또는 **Claude Code 안에서** `/sodam-ccc:fix`를 입력해 보세요.

## 7. 실행 방법

텔레그램으로 명령을 받으려면 Claude Code를 **특별한 방식으로** 켜야 합니다.

- **PowerShell(윈도우 검색창에 "PowerShell"을 입력하면 나오는 프로그램)에서 입력**:
  ```
  claude --channels plugin:telegram@claude-plugins-official
  ```
- 이렇게 켠 세션이 **떠 있는 동안에만** 폰 메시지를 받을 수 있습니다.
- `/sodam-ccc:install`이 이 단계가 필요할 때 정확한 명령을 다시 보여줍니다.

> ✅ **이렇게 나오면 정상입니다**: 평소 Claude Code를 켤 때와 같은 화면이 뜨고, 특별한 오류 문구가 없으면 정상입니다.
> (정확한 화면 문구는 실사용 검증 후 채워집니다.)

> ⚠️ **PC를 끄거나 이 창을 닫으면** 폰 메시지가 사라집니다(FAQ #1). **보냈는데 답이 없으면** → FAQ #2·#3 또는 `/sodam-ccc:fix`를 확인하세요.

## 10. 명령어 모음

**Claude Code 안에서 입력하는 명령**

| 명령 | 뭘 하나 |
|---|---|
| `/sodam-ccc:install` | 설치 마법사 — 부족한 것만 안내 |
| `/sodam-ccc:status` | 지금 몇 단계까지 됐는지 검사 |
| `/sodam-ccc:fix` | 안 될 때 원인을 찾아 안내 |

**폰 텔레그램에서 입력하는 것**

| 상황 | 입력 |
|---|---|
| 권한 승인 요청이 왔을 때 | 버튼을 누르거나 `yes <5글자코드>` |

> 위 명령은 텔레그램 채널 기능이 아직 "research preview"(정식 출시 전 시험 기능)라 바뀔 수 있습니다. 안 통하면 `/sodam-ccc:fix`를 실행해 보세요.
