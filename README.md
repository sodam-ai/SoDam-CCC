# SoDam-CCC — 텔레그램으로 내 컴퓨터에 말 걸기

> 🇰🇷 한국어 기본 문서입니다. English version: [`README.en.md`](./README.en.md)
> 이 문서는 **개발을 한 번도 안 해본 사람**, **AI·메신저·컴퓨터·모바일 기기를 처음 다루는 사람**을 기준으로 씁니다. "터미널이 뭔지", "경로가 뭔지" 같은 것도 처음 나올 때 한 줄로 풀어 설명합니다.

> ✅ **지금 이 문서가 서 있는 위치를 정직하게 밝힙니다** (2026-09-01 기준):
> - **실제로 이 PC에서 라이브로 확인된 것**: 설치 12단계 전체 흐름(마켓플레이스 등록 → 플러그인 설치 → 토큰 등록 → 페어링 → 안전 잠금), `/sodam-ccc:status`·`/sodam-ccc:fix` 정상 동작, 그리고 **폰에서 보낸 메시지가 실제로 PC를 거쳐 답장으로 돌아오는 것(왕복 성공)까지 전부 실제 화면으로 직접 확인했습니다.** ("안녕" → "안녕하세요! 연결됐어요. 무엇을 도와드릴까요?")
> - 이 확인 과정에서 실제로 두 번 막혔던 흔한 함정(① 설정 폴더 위치 불일치 ② 폴더 신뢰 확인 화면에서 멈춤)이 있었습니다. 원인과 해결법을 감추지 않고 [16. 문제·오류 대처 방법](#16-문제--오류-대처-방법)에 그대로 남겨뒀습니다 — 같은 상황을 겪어도 당황하지 않도록 하기 위해서입니다.
> - 이 문서의 "이렇게 나오면 정상입니다" 문구는 더 이상 예상이 아니라, 실제로 확인된 동작을 기준으로 씁니다. 다만 텔레그램 채널 기능 자체가 아직 "research preview"(정식 출시 전 시험판)라 앞으로 바뀔 수 있다는 점은 여전합니다.

## 1. 이게 뭔가요?

**한 문장 요약**: 폰(텔레그램 앱)으로 문자를 보내면, 내 컴퓨터에 있는 Claude Code(AI 코딩 도우미)가 그 문자를 읽고 일을 해준 뒤, 다시 폰으로 답장을 보내주는 기능(공식 이름: **Claude Code Channels**)을 — **처음 설치할 때, 다시 설치할 때, 고장났을 때** 헤매지 않도록 도와주는 도구입니다.

```
[폰에서 "회의록 정리해줘" 라고 보냄]
              │
              ▼
   ( SoDam-CCC 가 설치를 도와준 그 통로를 타고 )
              │
              ▼
[내 컴퓨터의 Claude Code 가 일을 함]
              │
              ▼
   [폰으로 결과 답장이 옴]
```

SoDam-CCC 자신은 **문자를 보내거나 받는 기능이 아닙니다.** 문자를 주고받는 기능(Claude Code Channels)은 Anthropic(Claude Code를 만든 회사)의 **공식 기능**입니다. SoDam-CCC는 그 공식 기능을 **설치·점검·수리**해 주는 조수입니다.

### 할 수 있는 것
- 지금 설치가 12단계 중 **몇 단계까지 됐는지** 검사해서 알려줍니다.
- 아직 안 된 단계만 골라서 **순서대로** 안내합니다(이미 된 건 다시 안 시킵니다).
- 폰이 갑자기 먹통일 때 **원인 후보를 검사**해서 어디가 문제인지 짚어줍니다.
- "허용된 사람만 명령을 보낼 수 있게" 잠그는 **안전 설정을 빠뜨리지 않게** 강제합니다.
- 채널을 켜는 프로세스(뒤에서 설명)를 **사용자 동의를 받은 뒤 대신 띄우고, 대신 꺼줄 수** 있습니다.

### 할 수 없는 것
- Claude Code 자체를 설치해주지 않습니다(Claude Code가 이미 깔려 있고 로그인돼 있다고 전제합니다).
- 텔레그램 봇을 대신 만들어주지 않습니다(봇을 만드는 건 폰에서 사람이 직접 하는 절차입니다).
- 봇 토큰(비밀번호 같은 값)을 대신 입력해주지 않습니다 — **SoDam-CCC는 이 값을 아예 보지도, 묻지도, 저장하지도 않습니다.**

## 5. 다운로드 / 설치 방법

1. **Claude Code 안에서** 아래를 입력합니다:
   ```
   /sodam-ccc:install
   ```
2. 지금 12단계 중 몇 단계까지 준비됐는지 검사한 뒤, **아직 안 된 것만** 순서대로 안내합니다.
3. 안내 중 일부는 **폰에서** 직접 해야 합니다(봇 만들기·토큰 확인·페어링(폰과 봇을 연결하는 절차)). 그때마다 "폰에서" 또는 "Claude Code 안에서"인지 정확히 알려줍니다.
4. 안전 잠금(허용된 사람만 명령을 보낼 수 있게 막는 설정)까지 끝나야 설치가 "완료"로 표시됩니다. **이 단계는 절대 생략되지 않습니다** — 안전 잠금이 안 됐는데 SoDam-CCC가 "완료됐습니다"라고 말하는 일은 설계상 없습니다.

> ✅ **이렇게 나오면 정상입니다**(설계 기준): 매 단계마다 지금 몇 단계인지(예: "7/12단계")와 다음에 뭘 하면 되는지 한 가지가 화면에 나옵니다. 이미 끝난 단계는 "이미 되어 있습니다"로 짧게만 표시되고 건너뜁니다.

> 💡 **설치 도중 플러그인 범위(스코프)를 고르라는 화면이 뜨면 반드시 `user`를 선택하세요.** 다른 걸 고르면 나중에 "다른 폴더에서 하니까 안 돼요"(16번 SYM-05) 문제가 생깁니다.

> 💡 **플러그인을 못 찾는다고 나오면** — 자동 업데이트가 꺼진 PC일 수 있습니다. 이럴 땐 **Claude Code 안에서** `/plugin marketplace update claude-plugins-official`을 한 번 입력한 뒤 다시 시도하면 됩니다. `/sodam-ccc:install`이 이 상황도 검사해서 알려줍니다.

> ⚠️ **재설치라면(기존 봇이 있다면)**: SoDam-CCC는 아무 기록도 남기지 않으므로, 지금 이 순간의 검사 결과 하나만으로 판단합니다. 이미 토큰이 등록돼 있으면 "새 봇을 만드세요"라고 시키지 않고 기존 봇을 그대로 씁니다 — 사람 손이 가는 단계가 **3개 이하**(토큰 복사·페어링 코드 확인·페어링 승인)로 줄어듭니다. 신규 설치는 여기에 "봇 만들기"가 하나 더 붙어 **4개 이하**입니다.

> ⚠️ **안 되면** → [17. FAQ #2](#17-faq-자주-묻는-질문)(봇이 답을 안 함) 또는 **Claude Code 안에서** `/sodam-ccc:fix`를 입력해 보세요.

## 6. 빠른 시작 (3분 안에 확인)

지금 상태를 가장 빨리 파악하는 순서입니다.

1. **Claude Code 안에서** `/sodam-ccc:status` 입력 → 지금 몇 단계인지, 뭐가 남았는지 바로 보여줍니다.
2. 부족한 게 있으면 **Claude Code 안에서** `/sodam-ccc:install` 입력 → 남은 것만 순서대로 안내받습니다.
3. "N/12단계"가 전부 채워지고 안전 잠금까지 끝나면, **폰 텔레그램에서 내 봇에게** "안녕"이라고 보내봅니다.
4. 답장이 오면 성공입니다. 조용하면 → [17. FAQ #3](#17-faq-자주-묻는-질문) 또는 `/sodam-ccc:fix`.

> ✅ 위 1~4번(상태 점검·설치 마법사·폰 왕복) 전부 이 PC에서 실제로 여러 차례 실행해 정상 동작을 확인했습니다.

## 7. 실행 방법

텔레그램으로 명령을 받으려면 Claude Code를 **평소와 다른 특별한 방식**으로 켜야 합니다. 일반 `claude` 명령으로 켠 세션은 폰 메시지를 받지 못합니다.

- **PowerShell(윈도우 검색창에 "PowerShell"을 입력하면 나오는 프로그램)에서 입력**:
  ```
  claude --channels plugin:telegram@claude-plugins-official
  ```
- 이렇게 켠 세션이 **떠 있는 동안에만** 폰 메시지를 받을 수 있습니다. 창을 닫으면 그 순간부터 못 받습니다.
- `/sodam-ccc:install`이 이 단계가 필요할 때 정확한 명령을 다시 보여줍니다.

### 🤖 SoDam-CCC가 대신 켜줄 수도 있습니다

위 명령을 사람이 PowerShell을 직접 열어 입력하는 대신, **Claude Code 안에서** `/sodam-ccc:install`(또는 `/sodam-ccc:fix`)에게 "채널을 켜줘"라고 하면, SoDam-CCC가:
1. 먼저 **이미 켜져 있는지부터 확인**합니다(중복으로 두 개를 띄우면 서로 충돌할 수 있어 절대 두 번 안 띄웁니다).
2. 안 켜져 있으면, 실행할 명령을 **화면에 그대로 보여주고 동의를 구한 뒤에만** 새 PowerShell 창을 대신 띄웁니다.
3. 그 창은 **숨기지 않고 눈에 보이게** 띄웁니다 — 몰래 백그라운드로 실행하지 않습니다.
4. 만약 이 PC의 다른 보호장치가 자동 실행 자체를 막으면(정상적인 이중 안전장치입니다), "PowerShell을 열고 이 명령을 직접 입력해주세요"로 자동 전환해 안내합니다.

채널을 끄고 싶을 때도 마찬가지로, SoDam-CCC가 띄운 그 창을 "꺼줘"라고 요청하면 동의를 받은 뒤 대신 종료해줍니다.

> ✅ **이렇게 나오면 정상입니다**(설계 기준): 평소 Claude Code를 켤 때와 같은 화면이 뜨고, 특별한 오류 문구가 없으면 정상입니다.

> ⚠️ **이 폴더에서 처음 실행하는 경우(신뢰 확인 화면)**: "Is this a project you created or one you trust? ❯ No, exit / Yes, I trust this folder"처럼 이 폴더를 신뢰하는지 묻는 화면이 뜨고 응답할 때까지 완전히 멈춰있을 수 있습니다. **이건 고장이 아니라 Claude Code 자체의 정상 보호 기능**이며 SoDam-CCC와 무관합니다. **↓(아래 방향키)로 "Yes, I trust this folder"로 옮긴 뒤 Enter**를 누르면 계속 진행됩니다. 기본 선택은 "No, exit"(종료)이므로, 방향키 없이 그냥 Enter만 누르면 꺼져버립니다 — 반드시 방향키로 옮긴 뒤 누르세요.

> ⚠️ **PC를 끄거나 이 창을 닫으면** 폰 메시지가 사라집니다([17. FAQ #1](#17-faq-자주-묻는-질문)). **보냈는데 답이 없으면** → [17. FAQ #2·#3](#17-faq-자주-묻는-질문) 또는 `/sodam-ccc:fix`를 확인하세요.

## 8. 사용 방법 (폰에서 뭐라고 보내면 되나)

설치가 끝나고 채널이 켜져 있으면, **폰 텔레그램에서 내 봇 채팅방에** 그냥 평소 Claude Code에게 말하듯 **자연어(보통 글)**로 보내면 됩니다.

```
예시:
"오늘 날씨 어때?"                (봇이 아니라 PC의 Claude Code가 실제로 작업 수행)
"방금 만든 파일 목록 보여줘"
"이 폴더에서 제일 큰 파일 찾아줘"
```

### 안 되는 것 (설계상 원래 이런 것 — 고장 아님)
- **슬래시 명령은 안 됩니다.** `/clear`·`/compact` 같은 명령은 터미널 화면 전용이라 채널로는 실행되지 않습니다(공식 기능요청 이슈로 개선 요청 중).
- **"어제 그거"처럼 지난 대화를 되짚는 건 못 알아듣습니다.** 텔레그램 봇은 과거 메시지를 다시 찾아볼 수 없고, 세션이 바뀌면 맥락도 이어지지 않습니다. "그 파일 이름이 뭐였는지 다시 알려줘"처럼 필요한 내용을 다시 말해주면 됩니다.
- **답변이 이상하게 잘려 보일 때가 있습니다.** 텔레그램 메시지 길이 제한 때문이며, 설정을 조정할 수 있습니다(16번 SYM-06).

### 위험한 작업을 시켰을 때
Claude Code가 `Bash`(명령 실행)·`Write`(파일 쓰기) 같은 위험도 높은 작업을 하려면, **PC 터미널 화면에 승인 요청이 뜨고 그 순간 세션이 멈춰서 기다립니다.** 폰에서 이 요청을 승인할 수 있습니다:
- 텔레그램 메시지에 뜨는 **버튼**을 누르거나
- `yes <5글자코드>` 형식의 **텍스트**를 직접 입력

승인하기 전까지는 그 작업이 진행되지 않습니다. 자세한 원리는 [15. 보안·데이터 흐름](#15-보안--데이터-흐름)에서 다룹니다.

## 9. 작동 원리

```
[폰: 텔레그램 앱]
       │  메시지 입력·전송
       ▼
[텔레그램(Telegram) 회사 서버]   ← Anthropic도 SoDam-CCC도 아닌, 텔레그램 자체의 서버
       │
       ▼
[내 PC: 텔레그램 채널 플러그인]   ← 이게 "떠 있어야" 다음 단계로 넘어감
       │  전달
       ▼
[내 PC: Claude Code 세션]        ← 반드시 `--channels`로 켠 세션이어야 함
       │  실제 작업 수행
       │  (위험한 작업이면 폰에 승인 요청부터 보냄)
       ▼
[내 PC: 작업 결과 생성]
       │
       ▼
[텔레그램 회사 서버] → [폰: 텔레그램 앱에 답장 도착]
```

**가장 중요한 한 가지**: 이 흐름의 중간(내 PC 부분)이 살아있지 않으면 전체가 끊깁니다.

> ⚠️ **PC가 꺼져 있거나, `--channels`로 켠 그 창이 닫혀 있으면 폰 메시지는 그냥 사라집니다.** 나중에 PC를 켠다고 밀린 메시지가 오는 게 아닙니다 — 그 순간 채널이 안 살아있었으므로 메시지 자체가 전달되지 못합니다. (상시로 계속 켜놓는 기능은 이 도구의 다음 단계(Phase 2) 계획이며, 지금은 아직 없습니다.)

SoDam-CCC 자신은 이 그림 어디에도 없습니다 — SoDam-CCC는 이 흐름이 살아있을 수 있게 **설정을 검사하고 도와주는 조수**일 뿐, 메시지가 지나가는 통로 자체가 아닙니다.

## 13. 워크플로우

### 핵심 흐름
```
/sodam-ccc:status  →  지금 몇 단계인지 파악
     │
     ▼
/sodam-ccc:install →  부족한 단계만 순서대로
     │
     ▼
안전 잠금(allowlist) + 폰 승인 확인 + 받음 표시(👀)
     │
     ▼
폰에서 "안녕" → 답장 도착  =  성공
     │
     ▼
(막히면) /sodam-ccc:fix → 증상 → 원인 → 조치
```

### 상황별 시나리오

**상황 A — 새 PC에서 처음 시작**
1. 새 PC에 Claude Code를 이미 설치해뒀다
2. `/sodam-ccc:install` 실행
3. 준비물을 검사하고 → 부족한 것만 안내 → 단계별로 확인하며 진행(봇 만들기 포함, 사람 손 4개 이하)
4. 폰에서 텔레그램으로 "안녕" → 답이 온다

**상황 B — 예전에 하다가 멈춘 상태를 이어서**
1. 예전에 설정하다 말았는데 어디까지 했는지 기억이 안 난다
2. `/sodam-ccc:status` 실행
3. "토큰까지는 됐고, 페어링만 남았습니다"처럼 **정확히 어디서 멈췄는지** 짚어준다
4. 그 단계부터 이어서 진행(기존 봇 재사용, 사람 손 3개 이하)

**상황 C — 갑자기 응답이 없음**
1. 폰에서 보냈는데 답이 없다
2. `/sodam-ccc:fix` 실행
3. 검사 15개를 먼저 자동으로 전부 돌려 실패한 것부터 보여준다. 그래도 못 찾으면 "봇이 아무 반응이 없어요" 같은 증상을 직접 물어봐서 원인 후보를 좁혀나간다
4. 원인에 맞는 조치를 안내(예: "권한 승인창이 PC에서 대기 중입니다. 폰에서 버튼으로 승인할 수 있습니다")

### 설치 마법사 내부 처리 방식 (참고)

`install`은 12단계를 성격에 따라 다섯 갈래로 나눠 처리합니다 — 섞어서 처리하지 않습니다.

| 갈래 | 예시 단계 | 처리 방식 |
|---|---|---|
| **읽기만으로 끝남** | 검사 결과 확인 | 결과만 보여주고 끝. 할 일 없으면 시키지 않음 |

## 15. 보안 · 데이터 흐름

### 내 정보는 어디에 저장되나

봇 토큰(가장 민감한 값)은 **내 컴퓨터 안에만** 저장됩니다(정확한 위치는 PC마다 다를 수 있습니다 — [12번](#12-파일문서-위치) 참고). 외부 서버로 전송되거나 SoDam-CCC가 어딘가로 복사하는 일은 없습니다.

**SoDam-CCC는 이 파일의 내용을 절대 열어보지 않습니다.** 파일이 "있는지 없는지"만 확인합니다 — 마치 봉투를 뜯지 않고 "봉투가 있는지"만 확인하는 것과 같습니다. 그래서 SoDam-CCC 자체가 토큰을 유출할 방법이 구조적으로 없습니다.

### 허용목록 = 승인 권한

텔레그램 허용목록에 등록된 사람은 단순히 "메시지를 보낼 수 있는 사람"이 아니라, **내 PC에서 파일 쓰기·명령 실행 같은 위험한 작업을 승인할 수 있는 사람**입니다. 승인 요청은 허용목록에 있는 **전원**에게 보내집니다. 그래서:
- SoDam-CCC는 허용목록에 **본인 외 다른 사람을 절대 자동으로 추가하지 않습니다.**
- 설치가 끝나는 순간, 이 권한이 얼마나 강력한지 반드시 화면에 고지합니다.
- 허용목록에 2명 이상이 있으면 `/sodam-ccc:status`가 경고로 알려줍니다.

### 3중 방어 (출력 규칙)

SoDam-CCC가 화면에 뭔가 보여줄 때 지키는 3단계 방어선입니다.

```
1층  안 읽는다      → 토큰 파일 내용에 애초에 접근하지 않음
2층  판정값만 쓴다   → "있음/없음/통과/실패"만 화면에 표시(원문 그대로 보여주지 않음)
3층  마스킹한다      → 혹시라도 토큰 형식 문자열이 화면에 나가려 하면 그 직전에 가림
```

### 위험한 작업 승인 흐름 (앞서 8번에서 다룬 것의 보안적 의미)

Claude Code가 파일을 쓰거나 명령을 실행하려면 승인이 필요합니다. 채널 모드에서는 이 승인 요청이 **폰으로도** 옵니다 — 이게 편리하지만 동시에 **가장 강력한 권한**이므로, 허용목록 관리가 이 도구에서 가장 중요하게 다뤄지는 이유입니다.

### 스크린샷·화면 공유 시 주의

이 도구의 실행 화면을 캡처해서 남에게 보여주거나 인터넷에 올릴 계획이 있다면, **내 계정 폴더 경로·사용자 아이디·토큰 형태의 문자열**이 찍히지 않았는지 반드시 확인하세요. SoDam-CCC 자체 출력은 이런 값을 안 보여주도록 설계돼 있지만, PowerShell 창이나 다른 화면까지 SoDam-CCC가 대신 가려주지는 못합니다.

### 위험 설정 자가 점검

`/sodam-ccc:status`·`/sodam-ccc:fix`는 매번 아래를 자동으로 함께 점검합니다.
- 허용목록 인원이 2명 이상인가 (경고)
- 단체방(그룹) 허용이 켜져 있는가 (경고)
- `--dangerously-`로 시작하는 위험한 실행 옵션을 쓴 흔적이 있는가 (경고)

SoDam-CCC는 위험한 실행 옵션(예: 권한 확인을 건너뛰는 옵션)을 **절대 권하거나 실행하지 않습니다.**

> ✅ **2026-09-01 재점검**: 위 세 가지 자가 점검 항목을 이 PC에서 직접 다시 실행해 전부 안전한 상태(허용목록 1명, 단체방 허용 0개, 위험 옵션 사용 흔적 없음)임을 확인했습니다. 이 과정에서 "단체방 허용 개수"를 세는 검사 방식 자체에 있던 작은 함정(0개인 정상 상태를 빈 값으로 잘못 표시할 수 있던 문제)을 찾아 고쳤습니다.

## 16. 문제 · 오류 대처 방법

`/sodam-ccc:fix`가 자동으로 검사·안내해주지만, 아래는 자주 겪는 증상을 미리 알아두고 싶을 때 참고하는 표입니다. 빈도: 🔴 매우 흔함 · 🟡 가끔 · 🟢 드묾 · ⚪ 사양(고장 아님).

### 🔴 봇이 아무 반응이 없어요
가장 흔한 원인 순서대로: ① `--channels` 없이 그냥 `claude`로 실행함 → 종료 후 [7번](#7-실행-방법)의 명령으로 다시 실행. ② Claude Code 세션 자체가 꺼져 있음 → 세션을 켠다(PC와 세션 둘 다 켜져 있어야 함). ③ 플러그인이 아직 설치가 안 됨. ④ 토큰이 아직 등록 안 됨.

**⑤ 채널 창은 떠 있는데 계속 안 되는 경우 — 봇 토큰이 무효화됐을 가능성**: BotFather에서 그 봇을 삭제했거나 다시 발급받았을 때 생깁니다. 텔레그램 앱에서 BotFather와의 대화를 열어 그 봇이 아직 있는지 먼저 확인하세요. 없거나 안 맞으면 [10번](#10-명령어-모음)의 토큰 등록 명령으로 새 토큰을 다시 등록하면 됩니다.

**⑥ 서버가 켜지자마자 곧바로 꺼지는 경우 — 설정 폴더 위치 불일치**(2026-09-01 실제로 겪은 사례): 토큰은 분명 등록했는데, 이 PC의 Claude Code 설정 폴더 위치가 예전에 바뀐 적이 있다면 토큰이 **엉뚱한(예전) 위치에만** 저장돼 있을 수 있습니다. 이때는 [10번](#10-명령어-모음)의 토큰 등록 명령을 **다시 한번** 실행하면 지금 기준으로 올바른 위치에 새로 저장됩니다. 그래도 안 되면 `/sodam-ccc:fix`에게 알려주세요 — 두 위치를 직접 비교해 옛 파일을 옮겨주는 대처법을 안내합니다.

**⑦ 채널을 켠 창이 뭔가에 멈춰 있는 경우 — "이 폴더를 신뢰합니까?" 확인 화면**(2026-09-01 실제로 겪은 사례): 그 폴더에서 Claude Code를 처음 실행하면 신뢰 여부를 묻는 화면이 뜨고, 대답할 때까지 그 창 전체가 멈춥니다(고장 아님, Claude Code 자체의 정상 보호 기능). 그 창을 직접 열어 화면에 "Is this a project you created or one you trust?" 같은 질문이 있는지 확인하세요. 있으면 [7번](#7-실행-방법)에 적은 대로 ↓(아래 방향키)로 "Yes, I trust this folder"를 고른 뒤 Enter를 누르면 이어서 진행됩니다.

### 🔴 메시지는 간 것 같은데 답이 없어요
가장 흔한 이유는 **PC 터미널 화면에 승인 요청이 떠서 대기 중**인 것입니다(고장 아님). 폰에서 버튼을 누르거나 `yes <5글자코드>`를 보내 승인하세요. 작업 자체가 오래 걸리는 중일 수도 있습니다 — `ackReaction`(받음 표시)을 켜두면 최소한 "전달은 됐다"는 걸 바로 알 수 있습니다.

### 🔴 `/plugin install`이 실패해요
마켓플레이스가 아직 등록 안 됐거나(`/plugin marketplace add anthropics/claude-plugins-official`), 카탈로그가 낡았을 수 있습니다(자동 갱신이 꺼진 PC라면 `/plugin marketplace update claude-plugins-official` 후 재시도).

### 🟡 페어링 코드가 안 와요
이미 안전 잠금(`allowlist`)이 걸려 있는데 내 계정이 아직 허용목록에 없는 상태일 수 있습니다. 이때는 정책을 잠시 `pairing`으로 되돌려 페어링한 뒤, **반드시 다시 `allowlist`로 잠가야** 합니다(안 잠그면 설치가 "완료"로 인정되지 않습니다). 봇 토큰 자체가 틀렸을 가능성도 확인하세요.

### 🟡 다른 폴더에서 하니까 안 돼요
설치할 때 스코프를 `project`로 골랐을 가능성이 큽니다. `user` 스코프로 다시 설치하세요([5번](#5-다운로드--설치-방법) 참고).

### 🟡 어제까지 잘 되던 게 갑자기 먹통이에요
Claude Code를 업데이트한 직후라면, 업데이트로 인한 일시적 회귀(공식 기능의 시험판 특성)일 수 있습니다. 버전이 바뀌었는지 확인하고, 공개된 이슈를 확인해 보세요. MCP(외부 도구 연결) 재연결 실패일 수도 있으니 세션을 재시작해보는 것도 방법입니다.

### 🟢 답변이 이상하게 잘려서 와요
텔레그램 메시지 길이 제한 때문입니다. 답변을 나누는 방식(청크) 설정을 조정할 수 있습니다.

### 🟢 설치했는데 채널이 등록이 안 됐대요
조직(회사) 계정 정책이 꺼져 있을 수 있습니다(단, **개인 Pro/Max 계정은 해당하지 않습니다**). 또는 `--channels` 뒤에 봇 이름을 정확히 안 적었을 수 있습니다.

### ⚪ "어제 그거"라고 했는데 못 알아들어요 — 고장 아님
텔레그램 봇은 과거 대화 내용을 다시 찾아볼 수 없습니다. 필요한 내용을 다시 말해주세요.

### ⚪ `/compact` 같은 걸 보냈는데 안 먹어요 — 고장 아님
슬래시 명령은 터미널 화면 전용이라 채널로는 실행되지 않는 것이 현재 사양입니다.

### 그래도 안 풀리면
**Claude Code 안에서** `/sodam-ccc:fix`를 입력하세요. 검사 15개를 자동으로 전부 돌려 실패한 것부터 순서대로 보여주고, 그래도 원인을 못 찾으면 증상을 하나씩 물어봐서 좁혀갑니다.

## 17. FAQ (자주 묻는 질문)

**Q1. PC를 꺼도 되나요?**
안 됩니다. PC가 꺼지거나 채널 세션(`--channels`로 켠 창)이 닫히면 그 순간 폰 메시지는 사라집니다. 나중에 켠다고 밀린 메시지가 오지 않습니다.

**Q2. 봇이 답을 안 해요.**
가장 먼저 `--channels`로 켰는지 확인하세요([16번](#16-문제--오류-대처-방법) 참고). `/sodam-ccc:fix`가 자동으로 원인 후보를 찾아줍니다.

**Q3. 보냈는데 조용해요.**
PC에서 승인 대기 중일 수 있습니다(고장 아님). PC 화면을 확인하거나 폰에서 승인해 보세요.

**Q4. 폰에서 승인할 수 있나요?**
됩니다. 텔레그램 메시지에 뜨는 버튼을 누르거나, `yes <5글자코드>` 형식의 텍스트를 보내면 됩니다.

**Q5. 다른 사람도 이 봇을 쓸 수 있나요?**
허용목록에 등록한 사람만 가능합니다. 다만 등록된 사람은 누구나 내 PC의 작업(파일 쓰기·명령 실행)을 승인할 수 있는 강력한 권한을 갖게 되므로, 정말 필요한 사람만 등록해야 합니다.

**Q6. 봇 토큰을 잃어버렸어요.**
텔레그램 앱에서 BotFather(공식 봇 관리 계정)와의 대화를 열어 내 봇 목록에서 다시 확인할 수 있습니다.

**Q7. 새 컴퓨터로 옮기려면 어떻게 하나요?**
봇 자체(토큰)는 그대로 재사용할 수 있습니다. 새 PC에 Claude Code와 SoDam-CCC를 설치한 뒤 `/sodam-ccc:install`을 실행하면, 재설치 흐름(기존 봇 재사용)으로 안내합니다.

**Q8. 돈이 드나요?**
SoDam-CCC 자체는 무료입니다(누구에게도 판매하지 않는 개인용 도구입니다). 다만 Claude 유료 요금제(Pro/Max)와 각 서비스의 이용약관은 별도로 적용됩니다.

**Q9. "어제 그거"라고 했는데 못 알아들어요.**
정상 동작입니다(고장 아님). 텔레그램 봇은 지난 대화를 다시 찾아볼 수 없습니다.

**Q10. `/compact` 같은 걸 보냈는데 안 먹어요.**
정상 동작입니다(고장 아님). 슬래시 명령은 채널로는 아직 지원되지 않습니다.

**Q11. 위험하지 않나요?**
허용목록을 본인 1명으로만 유지하고, 위험한 실행 옵션(권한 확인 건너뛰기 등)을 쓰지 않으면 이 구조상 위험은 크게 제한됩니다. SoDam-CCC는 이 두 가지를 항상 점검하고 경고합니다.

**Q12. 스크린샷 찍어서 물어봐도 되나요?**
가능합니다. 다만 화면에 내 계정 경로·아이디·토큰 형태의 문자열이 찍히지 않았는지 먼저 확인하고, 있다면 가리고 공유하세요.
